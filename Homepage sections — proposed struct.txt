# AQUA CARE SHOP — IMMERSIVE E-COMMERCE WEBSITE

Build a premium, modern, highly interactive e-commerce website for **Aqua Care Shop**, a water purifier store serving Chennai.

## Brand Positioning

Tagline:

“Chennai's Leading Destination for Water Purifiers, at Lower Prices Than Amazon & Flipkart”

The website must feel like a premium technology and lifestyle brand, not a traditional electronics shop.

## 1. Technology Stack

Use:

- Next.js with App Router
- TypeScript
- Tailwind CSS
- React
- Shadcn UI for reusable UI components
- React Three Fiber + Three.js for 3D scenes
- GSAP for scroll animations and cinematic transitions
- Lenis for smooth scrolling
- Lucide React for icons
- Zustand for cart state if needed
- TanStack Query for future API integration

Use pnpm as the package manager.

Use a clean, modular, scalable architecture.

- Primary Blue: #0077D9

Design direction:

- Premium and modern

- Cheap-looking card designs

- Overly cartoonish water effects
